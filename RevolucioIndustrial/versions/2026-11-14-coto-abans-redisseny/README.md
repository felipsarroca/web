# Animacions del cotó abans del redisseny (14 de novembre de 2026)

Còpia de seguretat feta a petició de Felip abans de substituir els SVG del capítol del cotó (`textil.html`). No s'enllaça des del web principal: només serveix per conservar els dissenys anteriors (motor 3D oblic `textil-models.js` + `textil-realista.js`) per si cal consultar-los o recuperar-los.

- `originals/`: còpia exacta byte a byte dels fitxers originals de la revisió de Git indicada a `manifest.json`, amb empremtes SHA-256.
- [`textil.html`](textil.html): còpia navegable independent del capítol del cotó.

## Com recuperar la versió anterior

Copia els fitxers d'`originals/` a l'arrel del projecte, o recupera'ls amb Git:

```bash
git checkout 43f66c5 -- RevolucioIndustrial/textil.html RevolucioIndustrial/js/textil*.js
```
