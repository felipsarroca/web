# Primera revisió conservada

Còpia íntegra de la versió publicada `9809026`, abans de la segona passada de claredat visual. Inclou el codi, els estils i les imatges per comparar-la independentment amb la nova.

Obre [el cotó d’aquesta versió](textil.html). El manifest conté la revisió de Git i les empremtes SHA-256 originals.

La versió inicial anterior a totes dues revisions continua conservada a `../2026-11-13-coto-abans-revisio/`.

Per recuperar només els fitxers del cotó d’aquesta primera revisió, des de l’arrel del projecte:

```powershell
python versions/2026-11-13-coto-primera-revisio/restaura.py
python versions/2026-11-13-coto-primera-revisio/restaura.py --aplica
```

La primera ordre és una previsualització. `--aplica` comprova les empremtes i recupera cinc fitxers del cotó. No esborra els fitxers nous, no restaura els estils ni el nucli compartits i no publica res.
