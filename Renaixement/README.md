**El Renaixement** és un recurs educatiu i de consulta sobre pintura, escultura i arquitectura, pensat especialment per a ESO i batxillerat. Combina un corpus artístic documentat, fitxes de lectura en diversos nivells, un visor d'alta resolució i una cronologia interactiva que permet entendre què passava al mateix temps a Itàlia, Flandes, França i els territoris hispànics.

**[Visita la web](https://felipsarroca.github.io/web/Renaixement/)** · **[Enllaç curt](https://ja.cat/renaixement)**

![Portada d'El Renaixement](captures/01-portada-desktop.png)

## Què ofereix

El projecte està construït al voltant de quatre maneres complementàries d'aprendre:

- **Explorar per temps:** cronologia de 1400 a 1614, amb artistes, obres i context històric en paral·lel.
- **Mirar les obres:** fitxes completes i imatges amb zoom profund per observar-ne els detalls.
- **Entendre conceptes:** explicacions de perspectiva, *sfumato*, *contrapposto*, ordres clàssics o planta central, sempre vinculades a exemples reals.
- **Comparar i relacionar:** activitats guiades, preguntes d'observació, respostes model i itineraris entre obres, artistes i contextos.

El corpus actual inclou:

| Contingut | Quantitat | Què hi trobareu |
|---|---:|---|
| Obres | **70** | Pintura, escultura i arquitectura d'Itàlia i de la resta d'Europa |
| Artistes | **35** | Biografia, activitat documentada, obres i context |
| Conceptes | **16** | Definició, exemple principal i activitats d'observació |
| Esdeveniments | **36** | Art, política, cultura i fites del període |
| Termes de glossari | **35** | Vocabulari artístic consultable des dels textos |
| Comparacions guiades | **6** | Pregunta, criteris d'observació i resposta model |
| Escoles arquitectòniques | **5** | Tradicions, trets i edificis representatius |

## Una cronologia pensada per aprendre

La cronologia és una de les peces centrals del projecte. Situa en carrils paral·lels el context històric, l'activitat documentada dels artistes i les obres. Els colors sempre van acompanyats d'icones i formes perquè la informació no depengui només de la percepció cromàtica.

![Vista general de la cronologia](captures/04-cronologia-general.png)

Permet començar amb una panoràmica breu i avançar cap al detall mitjançant:

- sis vistes preparades: panorama general, Itàlia al segle XV, Roma i Venècia, Europa, una disciplina i comparació d'artistes;
- navegació per segles o decennis;
- filtres per territori, disciplina, artista i obra;
- selecció simultània de fins a tres artistes;
- targetes de resum per decenni;
- enllaços directes a les fitxes d'obres i artistes;
- control per teclat i adaptació per a pantalles petites.

### Recorreguts didàctics

Tres recorreguts plantegen una pregunta històrica i preparen el període, els filtres i les obres rellevants:

1. **Què passava a Roma entre 1508 i 1512?** La Sixtina, les Estances de Rafael i sant Pere.
2. **Com es construeix la perspectiva lineal?** De Brunelleschi i Masaccio fins a Leonardo i Rafael.
3. **Flandes i Itàlia al segle XV.** Dues vies contemporànies: detall i oli, espai i perspectiva.

## Fitxes que conviden a mirar

Cada obra té una lectura en tres capes:

1. **Lectura ràpida:** imatge, autoria, data, tècnica, ubicació i «Per què és rellevant».
2. **Estudi:** context històric, anàlisi formal, funció i conceptes relacionats.
3. **Ampliació:** punts d'observació, curiositats, fonts, obres relacionades i accés al visor.

![Fitxa completa d'una obra](captures/03-fitxa.png)

Les afirmacions es vinculen a fonts institucionals i bibliografia de referència. Les fitxes distingeixen les dades documentades de les interpretacions i incorporen els crèdits, la procedència i la llicència de cada imatge.

## Visor d'alta resolució

Les obres disposen d'una piràmide local **Deep Zoom Image (DZI)**, visualitzada amb OpenSeadragon. Això permet ampliar detalls de grans fitxers sense carregar tota la imatge original de cop.

![Visor Deep Zoom amb anotacions](captures/07-visor.png)

El visor incorpora zoom progressiu, desplaçament fluid, pantalla completa, anotacions contextuals i preguntes d'observació. El catàleg serveix imatges WebP adaptatives i previsualitzacions LQIP per millorar la càrrega percebuda.

## Catàleg i navegació

![Catàleg d'obres](captures/02-cataleg.png)

La navegació connecta totes les capes del contingut:

- catàleg amb cerca i filtres per disciplina, període, territori, artista i concepte;
- fitxes d'artista amb cronologia vital i producció relacionada;
- seccions específiques d'arquitectura i del Renaixement fora d'Itàlia;
- comparacions guiades entre obres;
- glossari contextual consultable sense perdre el fil;
- URL pròpia i metadades socials per a cada obra, artista, concepte i secció.

La interfície és responsiva i està preparada tant per al projector de l'aula com per a la consulta individual amb ordinador o mòbil.

## Usos a l'aula

El recurs es pot utilitzar com a suport visual, material d'estudi o punt de partida per a activitats competencials:

- projectar una obra, ampliar-ne un detall i formular una hipòtesi abans de llegir la fitxa;
- comparar què feien dos o tres artistes contemporanis;
- reconstruir una seqüència causal a partir de la cronologia;
- cercar exemples d'un concepte formal i justificar-ne l'aplicació;
- respondre una comparació guiada i contrastar-la després amb la resposta model;
- preparar un comentari d'obra amb vocabulari específic i fonts citables.

## Desenvolupament local

### Requisits

- [Node.js 22](https://nodejs.org/) o posterior
- [Bun 1.3](https://bun.sh/) o posterior

### Posada en marxa

```powershell
git clone https://github.com/felipsarroca/web.git
cd web\Renaixement
bun install --frozen-lockfile
bun run dev
```

Obriu [http://localhost:3000](http://localhost:3000) al navegador. També es pot fer servir `npm install` i `npm run dev`, tot i que les proves estan definides amb Bun.

### Ordres disponibles

| Ordre | Funció |
|---|---|
| `bun run dev` | Inicia el servidor de desenvolupament a `127.0.0.1:3000` |
| `bun run test` | Executa les proves de dades, actius, rutes, pàgines i cronologia |
| `bun run lint` | Revisa el codi amb ESLint |
| `bun run build` | Genera una compilació autònoma per a servidor |
| `bun run start` | Inicia la compilació de producció |
| `bun run build:pages` | Genera l'exportació estàtica quan `GITHUB_PAGES=true` |

## Verificació

```powershell
bun run test
bun run lint
bun run build
```

La suite comprova la coherència de les dades i els identificadors, els actius d'imatge, les rutes, la renderització de les pàgines i el comportament de la cronologia.

## Publicació

### GitHub Pages

L'exportació estàtica incorpora el prefix `/web/Renaixement` a les rutes, les imatges i les piràmides DZI. Cada secció, obra, artista i concepte genera el seu propi `index.html`, de manera que els enllaços directes i les recàrregues funcionen correctament.

```powershell
$env:GITHUB_PAGES='true'
$env:NEXT_PUBLIC_SITE_URL='https://felipsarroca.github.io/web/Renaixement/'
bun run build:pages
```

El *workflow* del repositori publica el resultat a GitHub Pages quan s'actualitza la branca `main`.

### Servidor Node.js

Sense definir `GITHUB_PAGES`, la compilació genera una aplicació autònoma:

```powershell
bun run build
bun run start
```

El port per defecte és el `3000`; es pot canviar mitjançant la variable d'entorn `PORT`.

## Imatges, fonts i drets

Les obres del corpus són de domini públic. Els actius locals inclouen versions optimitzades per a la web i piràmides DZI per al visor.
